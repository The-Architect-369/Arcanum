# Part I — Tree nesting

## 1. Center-nested Tree fails

The first intuitive render places the Tree near the center of the stellar frame.

That is visually powerful but semantically unsafe.

Canonical doctrine states that Identity is continuity, not description. The Vitae Tree is a curriculum/symbolic coordinate system. Placing its stations around or through the Human/Identity center can imply that Malkuth, Keter, or another station is a description of the person.

### Disposition

```text
Tree hosted by Human / Identity center
→ FAIL AS DEFAULT
```

Candidate law:

> **Subframe Belongs to Faculty, Not Identity.**

## 2. Arcanum-hosted Tree passes

Vitae is an internal Arcanum faculty/curriculum structure. Therefore the clean scale hierarchy is:

The host transform is presentation-only:

```text

```

The Arcanum outer coordinate does not move when the participant changes class station.

## 3. The edge types remain different

The Tree registry contains twenty-two historical/comparison paths.

The ARCnet system study contains twenty-eight pairwise semantic relationships, only a future evidence-supported subset of which could ever become executable Edge Contracts.

These are different graph roles.

```text
Tree path
= internal curriculum / historical adjacency

ARCnet Edge Contract
= cross-system capability/information/value/action boundary
```

A Tree path cannot authorize network invocation, storage access, publication, settlement, governance, or capability.

Candidate law:

> **Internal Path Is Not Network Edge.**

## 4. Active Tree state remains local

The current 360-position Vitae grade index yields one active class sector every 36 positions.

The active class may highlight the corresponding Tree station.

- move the Arcanum outer vertex;
- change ARCnet relation classes;

No count-based or visual mapping is warranted. Even if a future rendering produces attractive near-alignments, geometric proximity creates no relationship.

# Part III — Cosmic movement correspondence tests

## 6. Nested transported systems — strong analogy

NASA describes the Sun as orbiting the center of the Milky Way while carrying the planets, asteroids, comets, and the rest of the solar system with it.

That is a genuine kinematic analogue for the transported-frame concept:

```text
local relations remain locally coherent
while the whole local frame changes position in a larger trajectory
```

For Arcanum:

```text
ARCnet local frame
moves through
Tempus × Vitae presentation history
```

The analogy stops at motion grammar. ARCnet transport is not gravitational dynamics or a claim about physical spacetime.

Candidate law:

> **A Local Frame May Travel Through a Larger Field Without Ceasing to Be Local.**

## 7. Barycentric motion — corrective, not correspondence

A simple solar-system drawing often places the Sun as a perfectly fixed center. Actual orbital mechanics is subtler: bodies orbit shared centers of mass, and the solar-system barycenter changes with planetary configuration.

This gives the Arcanum renderer an important warning.

The Human/Identity center is neither:

- a gravitational source;
- a center of mass;
- a Sun analogue;
- a computed barycenter.

It is a semantic representation of sovereignty/continuity inside this information architecture.

Candidate law:

> **Barycenter Is Not Identity.**

## 8. Multiple independent cycles — strong Tempus analogy

Earth participates in multiple motions simultaneously: rotation, annual revolution, axial precession, nutation, and longer orbital variations.

Tempus already wants a similar **multi-coordinate** posture:

```text
calendar
solar/seasonal
lunar
zodiac/planetary
decanic
other optional layers
```

The important correspondence is not the name of a cycle but the architecture:

```text
one moment
may have many simultaneous cycle coordinates
without those cycles collapsing into one master cause
```

Candidate law:

> **Many Cycles May Describe One Moment Without Becoming One Cause.**

## 9. Perfect circles fail as literal astronomy

Keplerian planetary motion is elliptical, and orbital speed changes around the ellipse.

Therefore the current circular Tempus fiber and torus should remain explicitly normalized phase diagrams.

They are not claims that planets move in perfect circles or at uniform true-anomaly speed.

This is especially important if Tempus later gains ephemeris-backed astronomy.

```text
civil-day clock phase
→ may be represented uniformly

actual planetary orbital coordinate
→ should come from an ephemeris / appropriate astronomical model
```

Candidate law:

> **Circular Phase Is a Coordinate Projection, Not an Orbital Claim.**

## 10. Orbital resonance — bounded mathematical analogy

Real systems can exhibit integer-ratio resonances. NASA describes Io, Europa, and Ganymede in a 4:2:1 orbital-count relationship; Pluto and Neptune provide another familiar resonant example.

This legitimizes a narrow Tempus research operation:

```text
cycle A phase
× cycle B phase
→ recurrence / beat / commensurability analysis
```

It does not legitimize:

```text
resonance → readiness
resonance → destiny
resonance → authority
resonance → recognition
```

Candidate law:

> **Resonance Is Relation, Not Permission.**

## 11. Apparent retrograde — unusually strong reference-frame analogy

A planet can appear to reverse direction against the sky because the observer is moving in another orbit. The underlying planet has not reversed its orbital time evolution.

This maps directly to our transport-render problem.

World-locked, path-aligned, geocentric, heliocentric, or other projections can produce very different visible trajectories while the underlying registered state remains the same.

For Tempus this suggests an explicit safety rule:

```text
astronomical retrograde
= observed/reference-frame motion metadata

NOT
= backward Vitae movement
= loss of recognition
= psychological regression
= bad timing
```

Candidate law:

> **Apparent Reversal May Be Frame-Relative; Becoming Does Not Run Backward.**

## 12. Precession and epoch — strong implementation lesson

NASA reference-system guidance emphasizes that Earth’s axes and celestial coordinates change over time through precession/nutation, which is why astronomical coordinate systems use reference epochs.

If Tempus eventually stores reproducible ephemeris-backed positions, `capturedAt` and `precision` are not enough by themselves.

A future astronomy context should consider carrying metadata such as:

```text
observer_reference
reference_frame
epoch_or_coordinate_epoch
ephemeris_model_or_source
captured_at
precision
interpretation: null
```

Candidate laws:

> **Epoch Before Interpretation.**

> **Ephemeris Before Symbolism.**

# Part IV — Strong failures

The following claims fail this audit:

```text
ARCnet is literally a solar system.
Human / Identity is literally the Sun.
The eight systems are planets.
The ten Tree stations are celestial bodies.
A planetary configuration causes Vitae advancement.
A conjunction/opposition grants permission or recognition.
Retrograde means a participant moves backward.
Resonance proves spiritual or institutional authority.
The current helix is a physical spacetime model.
```

Known celestial mechanics can produce physical effects through physical mechanisms — gravity, tides, radiation/insolation, orbital perturbation, and related processes. That fact does not establish causal pathways to human worth, recognition, governance authority, or curriculum advancement.

Candidate law:

> **Astronomy May Contextualize; It May Not Judge.**
